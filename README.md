# Checkerboard Coach

Clean rebuild of the Checkerboard squash coach app.

## Version 1.1 priorities
- Modular React/Vite structure
- Checkerboard challenge deck
- Singles, pairs, triples and blind challenge foundations
- Default scoring protocol
- Level 1–5 progression
- Large court-side controls

## Local development
```bash
npm install
npm run dev
```

## Netlify
Build command:
```bash
npm run build
```
Publish directory:
```bash
dist
```
